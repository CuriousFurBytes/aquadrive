Colors

A rose-tinted neutral palette with four accent options and semantic status tokens.

Base neutrals

Surfaces, borders, and text

--bg

light #F4EDED · dark #1C1828

Page background. Provides the calm foundation the UI sits on.

--surface

light #FFFFFF · dark #261F34

Cards, navbars and other containers that need a clear edge.

--surface-elevated

light #FFFFFF · dark #3B3247

Elevated surfaces — modals, popovers, hovered rows in tables.

--border

light #E0D5D5 · dark #3B3247

Hairline dividers between panels, inputs, list rows.

--text

light #1C1828 · dark #F4EDED

Default text color. Contrasted against --bg on both schemes.

--text-muted

light #7A6F7F · dark #C9B9BB

Secondary copy, labels, timestamps, helper text.

Accents

Status

Semantic feedback colors

--success

#52B788

Confirmations, successful saves, completed jobs.

--warning

#F9DB6D

Needs attention but not blocking — expiring carts, drafts.

--danger

#E66260

Destructive or error states. Pair with clear recovery text.

--info

#656EA4

Neutral informational messages. Aliased to the blue accent.

Scheme preview

Same tokens, two contexts

Light mode

Background uses a warm rose neutral (#F4EDED) with white surfaces. Text sits firmly at #1C1828 for strong contrast.

Use for: public-facing web, marketing, docs, customer flows.

Dark mode

Deep plum background (#1C1828) with elevated panels in #261F34. Accent colors keep their identity without clashing.

Use for: operator dashboards, late-night work, shop-floor tablets.
